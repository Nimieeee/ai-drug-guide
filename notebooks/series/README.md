## Episode 3: How to turn a molecule into data

`ep03_molecule_to_fingerprint.ipynb` takes huperzine A from SMILES to a 2,048-bit ECFP4 fingerprint with RDKit. It prints 18 heavy atoms, 41 set bits, the first ten set positions, and the highest count.
