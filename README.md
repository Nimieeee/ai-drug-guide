# AI DRUG guide: notebooks

Four free notebooks from AiSynth Labs for the "Get started in AI drug discovery" guide by Toluwanimi Odunewu ([@toluwanimiso](https://linktr.ee/ToluwanimiO)).

| Notebook | Projects | Open in Colab |
|---|---|---|
| 1. Python and data | 3 to 6 | [open](https://colab.research.google.com/github/Nimieeee/ai-drug-guide/blob/main/notebooks/ai_drug_nb1_python_and_data.ipynb) |
| 2. Machine learning | 7 to 10 | [open](https://colab.research.google.com/github/Nimieeee/ai-drug-guide/blob/main/notebooks/ai_drug_nb2_machine_learning.ipynb) |
| 3. Structure | 11 to 14 | [open](https://colab.research.google.com/github/Nimieeee/ai-drug-guide/blob/main/notebooks/ai_drug_nb3_structure.ipynb) |
| 4. Decide | 15 to 20 | [open](https://colab.research.google.com/github/Nimieeee/ai-drug-guide/blob/main/notebooks/ai_drug_nb4_decide.ipynb) |

Each notebook runs on its own, top to bottom, on a fresh Google Colab session (it installs RDKit in the first cell). Data comes from the ChEMBL, RCSB and PubChem web APIs, so nothing needs uploading. Numbers drift as the databases grow: date what you post.
